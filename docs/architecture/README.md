# Architecture Decision Records

Significant architectural decisions for this boilerplate, recorded so projects built on it know what was decided, why, and what was traded off.

## Index

| ADR                                         | Title                           | Status   |
| ------------------------------------------- | ------------------------------- | -------- |

## Adding an ADR

1. Copy the structure of an existing ADR into `NNNN-short-title.md`, using the next number.
2. Start with status **Proposed** and list the deciders who must sign off.
3. Record the context, options considered, decision, consequences and any prerequisites.
4. Add it to the index above in the same pull request.
5. Never rewrite an accepted ADR's decision. Supersede it with a new ADR and update both statuses.
